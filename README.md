## Project Overview

The **NGO Donation & Impact Tracking Dashboard** is a web-based application developed using **Java Spring Boot** to help Non-Governmental Organizations (NGOs) efficiently manage donation campaigns, donor information, and fund utilization. The system provides a centralized platform where administrators can create and monitor fundraising campaigns, record donations, and publish impact reports to ensure transparency.

Donors can register, browse active campaigns, make donations, view their donation history, and track the real-world impact of their contributions. By replacing manual record-keeping with a digital solution, the application improves operational efficiency, builds donor trust, and enables NGOs to manage their activities in a secure and organized manner.
